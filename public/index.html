      Earth Engine setup
      1. Create a Google Cloud project and enable the Earth Engine API; register it for Earth Engine.
      2. Authenticate: gcloud auth application-default login --scopes=https://www.googleapis.com/auth/earthengine,https://www.googleapis.com/auth/cloud-platform
      3. Set environment variables (never commit them), then restart the server:
        $env:EE_PROJECT="your-project-id"
        $env:EE_ACCESS_TOKEN=(gcloud auth application-default print-access-token)
